# Chart templates

A template is a set of settings, drawings, indicators, overlays, volume analysis tools, zoom level, chart settings and chart type saved in 1 file for further usage. One template can be applied in different workspaces.

Click on the![](<../../../../.gitbook/assets/1 (16).png>)button located in the toolbar of a chart to create a template.

![](<../../../../.gitbook/assets/2 (44).png>)

Then click on the «+» button and type a template name in the opened window.

![](<../../../../.gitbook/assets/3 (41).png>)

Created templates appear at the menu of templates. In order to apply a template, check the certain name in the list of created templates.

![](<../../../../.gitbook/assets/4 (13).png>)

By hovering a certain template name, a user can see 3 additional buttons for managing the template:

![](<../../../../.gitbook/assets/5 (17).png>)

* Re-save![](<../../../../.gitbook/assets/6 (2).png>)– allows to re-save a template with all settings from the chart.
* Rename![](<../../../../.gitbook/assets/7 (12).png>)– allows to rename a template. By clicking on this button, a window for renaming the template appears. A user can type a preferred template name.

![](<../../../../.gitbook/assets/8 (7).png>)

* Remove![](<../../../../.gitbook/assets/9 (5).png>)– allows to remove a template. By clicking on this button, a confirmation window appears, click ‘Yes’ in order to remove a template.

![](<../../../../.gitbook/assets/10 (2).png>)
